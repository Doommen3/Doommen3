### 🛠️ Featured Work

**[Follow The Money IL](https://github.com/Doommen3/Illinois_campaign_finance)** &nbsp;·&nbsp; [live ↗](https://www.followthemoneyil.com)
End-to-end campaign-finance platform ingesting Illinois state bulk filings + federal FEC data. **6.4M+ receipt rows, 530K+ filing totals, 1.3M+ donor-analytics rows**, deployed to production with scheduled syncs.
<br>`Python` · `Flask` · `SQLite` · `Playwright` · `OpenFEC API`

**[Legislative Bill Stats](https://github.com/Doommen3/congress-bill-stats)** &nbsp;·&nbsp; [live ↗](https://congress-bill-stats.onrender.com/)
Full-stack dashboard aggregating U.S. Congress + Illinois General Assembly bill activity, with search, CSV export, and D3.js network visualizations.
<br>`FastAPI` · `SQLite` · `JavaScript` · `Chart.js` · `D3.js`

**[DeKalb Scanner Alerts](https://github.com/Doommen3/police_scanner_transcription)**
Real-time police-scanner transcription + alerting. Ingests live Broadcastify audio via FFmpeg, runs Whisper STT (Int8), detects critical keywords with Aho-Corasick + fuzzy matching, and pushes alerts to email / Slack / a live WebSocket dashboard. Fully async, packaged as a standalone macOS app.
<br>`Python` · `faster-whisper` · `asyncio` · `FastAPI` · `WebSocket` · `RapidFuzz`

**[NIU Crime Map](https://github.com/Doommen3/Crimelogreader)** &nbsp;·&nbsp; [story ↗](https://northernstar.info/121584/news/northern-star-launches-niu-pd-crime-map/)
A 250-PDF scraper, geocoding pipeline, and interactive Leaflet map — published monthly in a live newsroom.
<br>`Python` · `R Shiny` · `Leaflet` · `Google Maps API`
